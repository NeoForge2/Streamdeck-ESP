Device connection

Connection settings are automatically picked up on the next reconnect attempt (usually within ~10 seconds). No application restart is required.

Appearance

Home Assistant (optional)

Create the token in Home Assistant from your user profile under "Long-Lived Access Tokens". It is required for bar/text widgets using Home Assistant entities and for Home Assistant actions.

MQTT (optional)

MQTT provides near real-time updates for bar, text and light-color widgets instead of waiting for the normal ~15-second REST polling cycle. It requires Home Assistant's mqtt_statestream integration using the same base_topic. Leave the broker host empty to disable MQTT. The application must currently be restarted after changing MQTT settings.
