Repris automatiquement au prochain essai de reconnexion (jusqu'a ~10s) - pas besoin de redemarrer l'icone.

Apparence

Home Assistant (facultatif)

Genere dans HA : profil utilisateur → bas de page → "Jetons d'acces longue duree". Necessaire pour les emplacements type "barre"/"texte" avec une source HA, et pour les actions type "home_assistant".

MQTT (facultatif)

Rend la mise a jour des emplacements barre/texte/couleur quasi instantanee au lieu d'attendre le sondage toutes les 15s. Necessite l'integration mqtt_statestream cote Home Assistant, avec le meme "Sujet de base" (base_topic) - voir le README de l'appli PC. Laisser l'hote vide desactive MQTT (le sondage REST classique continue de fonctionner). Un redemarrage de l'appli est necessaire apres modification de ces reglages.
